<h1 align="center">CHC – Computer Health Check</h1>

<p align="center">
  Бесплатное приложение для Windows, которое проверяет состояние компьютера (процессор, память, диски, видеокарту, аккумулятор, материнскую плату и стабильность системы) и объясняет результаты — от понятной сводки до исходных технических данных.

## Возможности

- **Оценка состояния (0–100)** для всего компьютера и каждого компонента с понятными статусами: *Норма / Совет / Внимание / Критично*.
- **Проблемы и рекомендации.** Для каждой находки объясняется, что не так, почему это важно и что делать.
- **От простого к техническому.** Каждая страница компонента начинается с короткой сводки, затем идут показания в реальном времени, технические характеристики, таблицы (модули памяти, атрибуты SMART, журнал событий) и все исходные датчики.
- **Процессор:** загрузка, температура, частоты, мощность, ядра и потоки, кэш, виртуализация.
- **Память:** использование, выделенная память, модули по слотам (тип, скорость, номер модели), определение одноканального режима и XMP/EXPO.
- **Накопители:** состояние по данным Windows и полный SMART (тот же движок, что и в CrystalDiskInfo, через DiskInfoToolkit): остаток ресурса, температура, часы работы, объём записи, переназначенные, ожидающие и неисправимые секторы, критические предупреждения NVMe и свободное место на каждом разделе.
- **Видеокарта:** температура, горячая точка, температура памяти, загрузка, мощность, VRAM, версия и возраст драйвера.
- **Аккумулятор** (ноутбуки): износ, паспортная ёмкость и ёмкость при полном заряде, циклы.
- **Материнская плата и система:** версия и возраст BIOS/UEFI, Secure Boot, TPM, версия Windows и время работы.
- **Стабильность:** внезапные выключения, синие экраны, аппаратные ошибки WHEA и ошибки дисков за последние 30 дней, а также проблемы в диспетчере устройств.
- **Датчики в реальном времени** — всё, что может прочитать LibreHardwareMonitor, с фильтром.
- **PDF-отчёт** в один клик с готовым оформлением. Также доступны экспорт в JSON и текстовая сводка для форумов. Серийные номера скрыты, пока вы их не включите.
- **8 языков:** English, Türkçe, Deutsch, Español, Français, Português (Brasil), Русский, 简体中文. Новые языки добавляются без перекомпиляции.
- Светлая и тёмная тема (как в Windows), дизайн Fluent в стиле Windows 11.

## Загрузка и запуск

1. Скачайте `CHC.exe` со страницы [Releases](../../releases).
2. Запустите его. Для работы CHC нужен [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) (если его нет, Windows предложит установить при первом запуске).

Без прав администратора CHC запускается в **ограниченном режиме**. Нажмите **Запустить от администратора** на боковой панели, чтобы получить данные SMART и дополнительные датчики.

Для температуры процессора и датчиков платы (вентиляторы, напряжения) также нужен бесплатный подписанный драйвер [PawnIO](https://pawnio.eu), который используют современные программы мониторинга. CHC работает и без него и сообщает, если он не установлен.

> CHC только читает информацию. Он не меняет настройки, не разгоняет оборудование и ничего не записывает на диски.

## Сборка из исходного кода

Требования: Windows 10/11 x64 и [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

```bash
git clone https://github.com/aliinal0/CHC.git
cd CHC
dotnet run --project src/CHC.App
```

Собрать один файл `CHC.exe`:

```bash
dotnet publish src/CHC.App -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

Хотите изменить порог или добавить проверку? Все правила находятся в `src/CHC.Core/Health/HealthAnalyzer.cs`, а тексты — под теми же ключами в языковых файлах.

## Переводы

Все тексты хранятся в `src/CHC.Core/Localization/Languages/<код>.json`. Чтобы добавить язык:

1. Скопируйте `en.json` в `<код>.json` (например, `it.json`).
2. Переведите значения, не меняя ключи и заполнители вроде `{0}`.
3. Откройте pull request или положите файл в папку `Languages` рядом с `CHC.exe`. После перезапуска язык появится в разделе **Настройки → Язык**.

Подробности — в [CONTRIBUTING.md](CONTRIBUTING.md).
